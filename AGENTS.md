# Project guidance

This is a personal, local-use application. Favor a straightforward, convenient experience over excessive security layers, permission prompts, or enterprise-style infrastructure. Keep protections proportionate to the actual use and avoid making local workflows harder without a concrete reason.

Keep testing proportional to the change. Use focused checks that establish the behavior works; avoid redundant tests, large test suites for small changes, or test scaffolding that costs more than the feature warrants.
